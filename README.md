# Portafolio de Angie Tatiana Agudelo Zárate

Este proyecto corresponde al portafolio personal desarrollado durante el Sprint 4 del programa de Desarrollo Web de TripleTen.

El sitio presenta mi perfil como Ingeniera de Software y desarrolladora web junior, mis habilidades y herramientas, algunos de mis proyectos y diferentes medios de contacto.

## Funcionalidades

- Diseño responsivo para escritorio, tablet y dispositivos móviles.
- Sección de presentación profesional.
- Descarga de hoja de vida.
- Enlace a mi perfil de GitHub.
- Sección de habilidades y herramientas.
- Presentación de proyectos destacados.
- Enlaces a repositorios y demostraciones de proyectos.
- Sección de contacto y redes sociales.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries
- Metodología BEM
- Git
- GitHub
- Figma

## Técnicas utilizadas

El proyecto fue desarrollado a partir de un diseño en Figma y adaptado para diferentes resoluciones de pantalla mediante diseño responsivo.

Se utilizaron Flexbox, unidades relativas, `calc()`, `aspect-ratio`, `object-fit`, pseudoelementos, gradientes y media queries para reproducir el diseño y adaptar su contenido a diferentes tamaños de pantalla.

Las fuentes Archivo Black y Open Sans están almacenadas localmente mediante `@font-face`.
